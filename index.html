For as long as there has been computing, one question has been harder than all the others: what time is it? Frontier models still can't answer it. They need tools. They need the internet. They apologise. So we built something different.

01 Multi-Tick Prediction

It doesn't predict the next token. It predicts the next tick.

Language models generate one token at a time. MTP-1302 pioneered Multi-Tick Prediction: a 32,768 Hz quartz oscillator, halved fifteen times, yielding exactly one tick per second. Then it does it again. It has been doing it, uninterrupted, since you started reading this sentence.

    arXiv:1302.0001 [time.QZ] · v1302

    MTP-1302: Multi-Tick Prediction Is All You Need

    The MTP Team*

    Abstract. We present MTP-1302, a three-head analog model for temporal inference. Unlike prior approaches, MTP-1302 is trained on zero tokens, requires zero GPUs and achieves state-of-the-art results on TimeBench with a drift of ±20 seconds per month. We find that scaling laws do not apply: the model is, and will remain, 38.5 mm. We release all weights (105 g).
